## 5. 标点与混排

- 中文语境用中文标点；括号补充说明用「（）；英文专有名词（GLM / DeepSeek / API / Token）保持半角原样，两侧不加空格（存量惯例）。
- 省略号：加载态「…」（单字符）或「...」（沿用所在组件现状，同一组件内统一）。
- 引用界面元素用「」：如「设置与更新 → AI 智能体」；路径分隔用 →。
- 数字 + 中文单位之间直接连接：`已选 3 张图片`。

## 6. 操作按钮动词

确认执行 / 取消 / 保存 / 关闭 / 重试 / 删除 / 复制 / 前往设置 / 加载更多 / 清除全部 / 提交任务 / 停止生成 / 再来一张 / 查看任务。
同一动作在不同页面必须用同一动词（例如删除确认一律「删除」+「取消」，不得出现「移除/去掉」）。

## 9. 图片来源（图库 Source Provenance，V4.1）

| 来源 kind | 显示（固定，禁止漂移） |
|---|---|
| local_import | 本地 |
| text_to_image | 文生图 |
| image_to_image | 图生图 |
| image_edit | 编辑结果 |
| batch_generation | 批量结果 |
| visual_recreation | 视觉复刻 |
| video_pose（CY Video Studio 动作白膜批） | 详情「来源」= CY Video Studio、「用途」= 动作白膜（两个概念两行）；卡片文字行「动作白膜 · ××」+ 角标 CY Video Studio |
| generated（任务记录缺失 / 输出目录扫描） | 生成结果 |

- 「本地」只允许描述用户导入（手动选择 / 拖入 / 复制进图库本地目录）的文件；微信 / QQ / 下载 / 桌面等任何外部源路径经 Gallery Drop 导入后一律「本地」（外部源路径 ≠ 资产来源，禁止按路径含 WeChat / QQ 等关键词细分来源）；linked task 的生成资产永远不得显示为「本地」。
- **来源（Source，从哪里进入 CyImagePro）与用途（Asset Type，在业务里是什么，如「动作白膜」「人物替换参考图」）是两个概念、两个 label**；用途只有真实存在业务 metadata 时才显示，普通本地 / 生成图片不得默认补「类型：生成结果」。
- 来源唯一 resolver：`src/utils/imageSource.ts`（禁止页面内散落归类 / local 兜底）；详情 / Viewer 行唯一来源 `src/features/gallery/imageDetailMetadata.ts`（内部复用 resolveImageSource，Card / Filter / Detail / Viewer 不分叉）。

### 9a. 详情字段名（Gallery 详情 Modal / ImageViewer metadata）

| 字段 | 说明 |
|---|---|
| 文件名 | 真实文件名（长名 ellipsis + tooltip，不撑破侧栏） |
| 来源 | resolver 来源词（动作白膜 = CY Video Studio） |
| 用途 | 仅存在真实业务用途 metadata 的资产（动作白膜 / 参考图类） |
| 导入时间 / 生成时间 | 本地=导入时间，其余=生成时间（同一 created_at，按语义命名，不伪造字段） |
| 尺寸 / 格式 / 文件大小 | 有真实数据才显示（格式来自扩展名、文件大小来自 Rust file_size；禁止造 DPI / EXIF / 作者类字段） |
| 生成模型 / 任务 ID | 仅任务关联资产 |
| 动作 / 视角 / 关键帧 / Batch ID / Slot ID / Request ID / Source Feature / Preset Version | 动作白膜批次区（标题「动作白膜」；来源 / 用途在基础信息区，不重复） |

禁止 label：「类型」「来源类型」「生成类型」「资产来源」「图片来源」。

## 11. 图片库拖拽导入（V4.1）

唯一来源：`features/gallery/galleryFileDrop.ts`（`galleryDropOverlayCopy` / `describeImportResult`）；业务组件禁止随手拼这些文案。

| 场景 | 固定文案 |
|---|---|
| Overlay 主标题（纯合法多图） | `释放即可导入 N 张图片`（单张：`释放即可导入图片`） |
| Overlay 主标题（混合拖入） | `可导入 N 张图片` + 副行 `M 个文件不支持` |
| Overlay 主标题（全部非法） | `没有可导入的图片` + 副行 `仅支持 PNG、JPG、JPEG、WebP 图片` |
| Overlay 说明行 | `图片将保存到 CyImagePro 图片库` |
| Overlay 格式行 | `PNG · JPG · JPEG · WebP` |
| 导入中 Toast | `正在导入 N 张图片…`（禁止伪百分比） |
| 全部成功 Toast | `已导入 N 张图片` |
| 部分失败 Toast | `已导入 N 张，M 张失败`（+ 独立失败明细 Toast：`文件名：原因`，分号连接） |
| 含已在图片库 Toast | `已导入 N 张图片，M 张已在图片库中` |
| 空投 Toast | `没有可导入的图片`（title：`仅支持 PNG、JPG、JPEG、WebP 图片。`） |
| Rust 失败原因（failed.reason） | `文件不存在` / `不支持文件夹` / `不支持该文件格式` / `复制失败: …` |
| Rust 跳过原因（skipped.reason） | `已在图片库目录中` / `已在图片库中` |
| 未配置目录错误 | `请先在「设置与更新 → 图片与文件」中配置本地导入目录` |
