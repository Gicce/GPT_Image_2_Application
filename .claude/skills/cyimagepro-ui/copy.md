## 5. 标点与混排

- 中文语境用中文标点；括号补充说明用「（）；英文专有名词（GLM / DeepSeek / API / Token）保持半角原样，两侧不加空格（存量惯例）。
- 省略号：加载态「…」（单字符）或「...」（沿用所在组件现状，同一组件内统一）。
- 引用界面元素用「」：如「设置与更新 → AI 智能体」；路径分隔用 →。
- 数字 + 中文单位之间直接连接：`已选 3 张图片`。

## 6. 操作按钮动词

确认执行 / 取消 / 保存 / 关闭 / 重试 / 删除 / 复制 / 前往设置 / 加载更多 / 清除全部 / 提交任务 / 停止生成 / 再来一张 / 查看任务。
同一动作在不同页面必须用同一动词（例如删除确认一律「删除」+「取消」，不得出现「移除/去掉」）。

失败分类标题（唯一来源 `classifyGenerationFailure`，禁止页面手写）：

| category | 标题 | 建议 |
|---|---|---|
| upstream_5xx | 上游图片服务异常 | 通常属于临时服务异常，建议稍后重试。 |
| timeout | 生成请求超时 | 网络波动或服务繁忙时可能出现，建议重新生成。 |
| rate_limit | 请求过于频繁 | 稍等片刻后重新生成即可，无需修改任何参数。 |
| auth | 模型服务授权失败 | 请检查当前模型服务配置或 API 凭据。 |
| auth（运行 Token 未配置） | 当前没有可用的运行 Token | 请重新登录或等待运行配置下发后再重试。 |
| insufficient_balance | 模型服务余额不足 | 请前往「我的账户」充值后再重试。 |
| invalid_request | 生成参数不符合当前模型要求 | 请检查参考图、尺寸或生成参数后重试。 |
| invalid_request（text_conversation_not_supported） | 模型调用方式与当前模型能力不匹配 | 可直接重新生成；若持续出现请检查服务商模型配置。 |

| network | 网络连接异常 | 请检查网络或代理设置后重试（「设置与更新 → 一键检查运行环境」可一键诊断）。 |
